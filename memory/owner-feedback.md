The owner said (2026-08-30, terminal UI work): do not show me intermediate states; ship what
you think is the best-looking version, then I launch `hcode` and look. Feedback then comes as a
screenshot plus one sentence ("the input box has no second edge", "output should start from the
top"). "Iterate fast, don't be afraid."

**Why:** reviewing drafts costs the owner more than a wrong final that gets one more round.

**How to apply:** make every design decision yourself, commit, and reply with one line saying
what to launch and where to look. Read a screenshot literally — which render path is on screen
(the composer, usually), what is missing — and fix that path first. See [[render-paths]].
